# Python Virtual Environment Guideline

- Always activate and use the Python virtual environment located in `.venv` (`c:\Users\WINDOWS 11\Documents\antigravity\machine_learning\.venv`).
- For command execution in PowerShell / Windows terminal:
  - Run scripts and commands using `.\.venv\Scripts\python.exe` or `.\.venv\Scripts\pip.exe`.
  - Alternatively, activate the virtual environment before running Python commands using `.\.venv\Scripts\Activate.ps1`.
- Never use or install dependencies into the global system Python installation.
