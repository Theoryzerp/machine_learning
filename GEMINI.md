# Workspace Rules & Configuration

## Entorno Virtual (Python Environment)
- Siempre utilizar y conectarse al entorno virtual de Python ubicado en `.venv`.
- En Windows (PowerShell):
  - Ejecutar scripts y comandos utilizando `.\.venv\Scripts\python.exe` o `.\.venv\Scripts\pip.exe`.
  - O activar el entorno con `.\.venv\Scripts\Activate.ps1`.
- No utilizar ni modificar la instalación global de Python del sistema.
